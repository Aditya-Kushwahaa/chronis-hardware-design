# Chronis Hardware Design

## Overview

This repository contains the complete hardware design work completed for Task 2 of the Chronis AI Wearable internship.

The objective is to transform the hardware concept into a complete electrical blueprint before hardware procurement.

## Deliverables

- Battery Research
- Component Compatibility Verification
- Wiring Blueprint
- Pin Mapping
- Privacy Switch Firmware
- Bring-up Checklist
- Privacy Brief
- Hardware Readiness Report
